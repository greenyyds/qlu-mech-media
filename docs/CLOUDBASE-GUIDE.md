# CloudBase 环境创建指南（让数据真正共享）

> 目标：在腾讯云创建 CloudBase（云开发）免费环境，拿到**环境 ID**，
> 填入项目 `src/config/cloudConfig.js` 后，任务 / 值班表 / 反馈即全员共享。
> 预计耗时：约 10 分钟（含等待环境创建）。
> 前置：已注册腾讯云账号并完成实名（EdgeOne 部署时已做过）。

---

## 入口网址（任选其一）

1. **云开发控制台（推荐）**：https://console.cloud.tencent.com/tcb
2. 产品介绍页（从"立即使用"进入）：https://cloud.tencent.com/product/tcb
3. 或在腾讯云控制台顶部**搜索框**输入「**云开发**」/「**CloudBase**」直接跳转

> 如果打不开：多为网络临时问题，刷新或换网络重试。

## 操作步骤

### 第 1 步：进入控制台

打开 https://console.cloud.tencent.com/tcb → 用腾讯云账号登录（微信扫码即可）

### 第 2 步：开通服务

- 首次进入会看到"云开发 CloudBase"服务介绍页 → 点击「**立即开通**」/「**免费开通**」
- 勾选同意服务协议 → 确认（开通不产生费用）

### 第 3 步：创建环境

1. 进入环境列表页 → 点击「**新建环境**」（或"创建环境"）
2. 填写：
   - **环境名称**：随意，建议 `qlu-mech-media`（仅内部标识）
   - **计费方式**：选「**免费额度（体验环境）**」——注意不要选成按量付费
   - **环境区域**：选「**上海**」或「**广州**」（中国大陆区域，访问快）
   - ⚠️ **数据库类型：必须选「文档数据库」（MongoDB）**！
     （本项目使用文档数据库 API。若选成 PostgreSQL，页面将报
     "This environment has no document database instance"，全站数据功能不可用）
3. 点击「**确定**」/「创建」

> 如创建界面没有数据库类型选项：可能默认文档数据库（无需选择），
> 创建后可用 `node scripts/configure-cloudbase.mjs` 或直接问 AI 验证类型。

### 第 4 步：等待创建完成

- 创建过程约 1-3 分钟，页面会自动刷新环境状态
- 状态变为「**运行中**」即可

### 第 5 步：找到环境 ID

在环境列表（或环境概览页）中：

- 每个环境下方有一行小字，形如：**环境 ID：`qlu-mech-media-1a2b3c`**
- 复制这串 ID（形如 `xxx-xxxxxx`）

### 第 6 步：把环境 ID 发给我

把环境 ID 发给我（或自己填入项目 `src/config/cloudConfig.js` 的 `envId` 字段），
我会完成：安全规则配置（三个集合公开读写）→ 构建 → 上线。

## 完成后如何自检（可选）

在浏览器打开网站 → 任务看板头部徽标应从「本机数据」变为**绿色「云端共享」**；
在手机和电脑各开一次页面，一边添加任务、另一边刷新可见。

## 常见问题

| 问题 | 说明 |
| --- | --- |
| 找不到"新建环境"按钮 | 确认已在环境列表页；若提示需先开通/实名，按页面引导完成 |
| 只有"按量付费"选项？ | 体验环境入口在"免费额度/体验环境"标签下；如界面有变化，选最低成本的免费套餐即可 |
| 环境创建失败 | 多为实名未通过或区域问题，按页面提示处理 |
| 免费额度够吗 | 体验环境约 3000 资源点/月，日常查询足够；超额会暂停，届时可降级本地模式或升级 |
