## 一、修复：Switch 组件统一重构（Bug 1）

**现状**：新闻工具"生成文首摘要"开关、反馈页"匿名提交"开关的白色圆点在切换时位移异常/越界感。

**方案**：
- 新建共用组件 `src/components/Toggle.jsx`（`role="switch"`、`aria-checked`、键盘可操作）
- 布局从 translate 位移改为 **flex 两端对齐 + 内边距**（`justify-start/justify-end`），容器 `overflow-hidden` 兜底，彻底消除越界
- 两处开关统一替换；深色模式样式同步（轨道色、knob 阴影）
- 冒烟测试增加开关断言（切换后 aria-checked 同步、无越界）

## 二、AI 模型双模式（Bug 2 + 功能升级）

**现状**：实际模型已是 glm-4.5-flash，但 UI 徽标仍写死"GLM-4-Flash"（newsToolConfig modelLabel + NewsTool 注释共 3 处）。

**方案**：
- `src/config/aiConfig.js` 重构为双模型配置：
  ```js
  export const aiModels = {
    quick: { id: 'quick', label: '快速', model: 'glm-4-flash',   note: '响应快、节省额度' },
    deep:  { id: 'deep',  label: '深度', model: 'glm-4.5-flash', note: '文字质量更高（推荐）' },
  }
  export const aiConfig = { defaultMode: 'deep', baseUrl, apiKey, temperature, maxTokens }
  ```
- `newsService.streamDraft(options, signal)` 增加 mode 参数；历史记录保存所用 mode
- **UI**：选项面板顶部"模型模式"chips（快速/深度）；模块头徽标动态显示当前型号；预览区底部注明模式与型号
- 删除 `newsToolConfig.js` 的写死 modelLabel，改由 aiModels 驱动

## 五、迭代与日志规范（生命周期保障 · 强制）

> 目标：保证网站生命周期与可持续性——**任何一次迭代，文档变更与代码变更同等重要**。

**每次迭代完成后必须（验收项）：**
1. **`CHANGELOG.md`**：新增版本条目（版本号 vX.Y.Z、日期、变更内容、关键决策、踩坑记录）
2. **`README.md`**：功能清单/架构/已知事项如有变化必须同步
3. **`MAINTENANCE.md`**：维护地图、故障排查如有新增必须同步
4. **`docs/` 相关**：涉及部署/环境/架构决策时更新对应文档
5. **冒烟测试全绿**：`npm run smoke`（本地可执行时）或说明受限原因
6. **git 提交信息规范**：`vX.Y: 变更摘要` 格式

**文档更新优先级**：与代码改动同批提交，不允许"先上线后补文档"。

## 六、验收标准

1. 两处开关：切换方向正确、圆点不越界、键盘可操作、aria 同步（冒烟断言）
2. 模型双模式：快速/深度切换生效（真实生成验证两模式），徽标动态显示型号，默认深度
3. 工具链接：醒图/秀米可访问（新窗口），五品牌色符合方案，深色模式可辨识
4. 教程中心：四板块渲染、三板块"暂未开通"、摄影页分步引导可用（翻页/键盘/进度）、图文加载 <500KB
5. 既有功能不回退（冒烟全绿、构建零报错）
6. **文档同步**：README / MAINTENANCE / CHANGELOG（v4.0.0）全部更新并同批提交
