# CloudBase 环境配置（开启共享的最后一步）

> 前置：已创建环境（见 `docs/CLOUDBASE-GUIDE.md`），环境 ID：`qlu-mech-media-d1gtbtg87209c8a39`
> 目标：开启**匿名登录** + 创建**3 个集合** + 设置**公开读写规则**。
> 完成后，任务 / 值班表 / 反馈即全员共享（约 5 分钟）。
> 控制台入口：https://console.cloud.tencent.com/tcb → 进入环境 `qlu-mech-media-d1gtbtg87209c8a39`

---

## 第 1 步：开启匿名登录（必做，否则页面报"登录方式未开启"）

1. 环境概览页 → 左侧菜单找「**登录授权**」（或"身份验证 / Authentication"）
2. 找到「**匿名登录**」→ 点击**开启**
3. 确认开启成功（开关变绿/显示"已开启"）

## 第 2 步：创建 3 个集合（必做，否则读写报"集合不存在"）

1. 左侧菜单 →「**数据库**」（Database）
2. 点「**新建集合**」→ 集合名填 **`tasks`** → 确定
3. 重复创建 **`roster`**、**`feedback`**（共 3 个）

## 第 3 步：每个集合设置"所有用户可读写"（必做，否则成员间看不到彼此数据）

对 `tasks`、`roster`、`feedback` **分别**执行：

1. 点击集合名进入集合详情
2. 顶部/右侧找「**权限设置**」（或"安全规则"）
3. 权限模板选择：**「所有用户可读写」**（如无预设模板，选"自定义安全规则"，填入下方 JSON）
   ```json
   { "read": true, "write": true }
   ```
4. 保存

## 常见问题

| 问题 | 处理 |
|---|---|
| 找不到"登录授权"菜单 | 不同版本控制台菜单位置略有差异，可搜「身份验证」「Authentication」；或发截图给我 |
| 集合已存在？ | 之前测试可能未创建成功（匿名登录未开时写入被拒），确认 3 个集合都存在 |
| 权限设置有预设选项 | 直接选「所有用户可读写」即可 |
| 完成后仍显示离线模式 | 清空浏览器缓存/重新打开（PWA 缓存旧版）；仍不行联系我 |
