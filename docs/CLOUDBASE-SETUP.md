## 新版控制台说明（云开发开发平台）

腾讯云已升级新版控制台（"云开发开发平台"），旧版入口（控制台 → 云开发 → 数据库）会提示跳转。
**新版入口：https://tcb.cloud.tencent.com/（或旧控制台里点"前往云开发开发平台"）**。

新版界面找不到菜单时的通用办法：**页面顶部搜索框**，直接搜"数据库 / 身份认证 / 匿名登录 / Web 安全域名"，点搜索结果即可跳转到对应页面。

## 第 1 步：开启匿名登录（必做）

1. 环境左侧菜单（或搜索）→「**身份认证**」（旧版叫"登录授权"）
2. 找到「**匿名登录**」→ 打开开关

## 第 2 步：配置 Web 安全域名（必做，否则 CORS 拦截报离线）

**格式要求：域名不带 `http://` 或 `https://` 前缀**（如 `greenyyds.github.io`）。

- 控制台方式：环境左侧菜单（或搜索）→「**Web 安全域名**」→ 添加 `greenyyds.github.io` → 保存
- CLI 方式（需 API 密钥）：
  ```bash
  npm i -g @cloudbase/cli
  tcb login --apiKeyId <SecretId> --apiKey <SecretKey>
  tcb cors add greenyyds.github.io -e <envId>     # 交互确认输入 y
  tcb cors list -e <envId>                          # 验证
  tcb logout
  ```

> 排查经验：曾用 TCB SDK 的 CreateAuthDomain 添加（带 https:// 前缀）仍被 CORS 拦截；
> 正确做法是 `tcb cors` 命令且**不带协议前缀**。添加后浏览器刷新页面（或等 30 秒自动恢复）即可。

## 第 3 步：创建 3 个集合（必做）

1. 环境左侧菜单（或搜索）→「**数据库**」
2. 「**新建集合**」→ 依次创建：`tasks`、`roster`、`feedback`

## 第 4 步：每个集合设置"所有用户可读写"（必做）

对 `tasks`、`roster`、`feedback` 分别：

1. 点集合名进入 → 找「**权限设置**」或「**安全规则**」
2. 模板选「**所有用户可读写**」；若无模板，选"自定义/编辑规则"，填入：
   ```json
   { "read": true, "write": true }
   ```
3. 保存

| 问题 | 处理 |

| 找不到"身份认证/登录授权"菜单 | 用页面顶部搜索框搜"匿名登录"；或发截图给我 |
